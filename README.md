## Project Overview

Blinkit Sales Analysis is a **Power BI dashboard project** developed to analyze sales performance across different products and outlet characteristics. The dashboard provides an interactive view of sales, product categories, outlet types, outlet sizes, outlet locations, and establishment years.

## Objectives

* Analyze overall sales performance.
* Identify the top-performing item categories.
* Analyze sales based on item fat content.
* Compare sales across different outlet types.
* Analyze sales performance by outlet size.
* Compare sales across different outlet location types.
* Analyze sales trends based on outlet establishment year.
* Provide interactive analysis using Power BI filters and slicers.

## Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Cleaning**
* **Data Visualization**

## Key Analysis

* Total Sales
* Average Sales
* Number of Items
* Average Rating
* Sales by Item Type
* Sales by Item Fat Content
* Sales by Outlet Type
